# APIManager

精简版 AI 中转站账号管理浏览器扩展——只做三件事：**账号管理（分组 + 标签）**、**余额查看**、**每日自动签到**。

灵感来自 [all-api-hub](https://github.com/qixing-jk/all-api-hub)：它很强大，但如果你只用得上账号管理和签到，这个精简版会更清爽。本项目为**独立实现**，仅参考了各中转站的公开接口行为（端点、请求头、响应语义），未复用其代码（all-api-hub 为 AGPL-3.0 协议）。

## 功能

- **账号管理**：录入站点账号（URL / Access Token / 用户 ID），手动刷新余额；签到成功后自动顺带刷新
- **登录凭证**：为账号保存登录方式（账号密码 / OAuth 授权记录）——密码经主密码派生密钥（PBKDF2 + AES-GCM）加密后存本地，可解锁查看/复制；仅想记凭证、不接签到的站也能录入
- **双层分类**：分组（popup 主列表按组折叠，适合"常用 / 备用 / 白嫖"）+ 多标签（快速筛选）
- **自动签到**：每日在设定窗口随机执行或按固定时刻执行；仅临时故障自动重试，至少间隔 30 分钟、每日最多重试 2 次，并遵守站点限流等待时间；完成后系统通知
- **一键迁移**：直接导入 all-api-hub 的备份 JSON（账号、Token、标签自动映射）
- **自身备份**：导出 / 合并导入 / 覆盖导入

## 支持的站点类型

| 类型 | 签到 | 鉴权 |
|---|---|---|
| New API 系 | ✅ | Access Token；新版支持浏览器会话识别与自动续期 |
| Veloera | ✅ | Access Token |
| VoAPI v2 | ✅ | 页面 JWT（会过期，过期后扩展会标黄提醒更新） |
| AnyRouter | ✅ | 浏览器 Cookie（需保持该站在浏览器中已登录） |
| Sub2API | ❌（无内置签到） | Access Token（仅查余额） |
| 其他 | ❌ | 通用记录型——仅账号管理，不拉余额不签到 |

新版 New API 的账号和访问令牌可能只保存在页面内存中。登录站点后点击扩展「识别」，扩展会通过站点的会话接口读取账号，并在令牌过期时续期。请保持该站在同一浏览器中登录；退出、切换账号或更换浏览器后，需要重新登录并识别。刷新凭据保留在站点的 HttpOnly Cookie 中，不复制到扩展或备份。

账号识别会先向站点核对当前登录身份，旧缓存不直接作为识别结果。缓存 Token 经核验后才用于更新账号；身份不确定、页面跳转或请求超时都会停止识别，已有账号凭据保持原值。

遇到 `request origin is not allowed` 或明确的人机验证拦截时，扩展可在同源页面内重试一次；只读请求遇到 HTML 登录页也可使用此回退。签到提交返回普通 HTML 或页面回退超时，则先查询状态，避免重复提交。优先复用已打开的站点页面，没有页面时临时打开后台标签页，完成后关闭；Cookie 认证会先核对账号。

旧版 AnyRouter 直接使用站点页面的 Cookie 查询余额；签到时会加载独立的后台控制台页，触发站点自身的自动签到，再确认结果。请求超时会停止等待并提示原因，今日用量接口无响应时仍会更新已获取的余额。

New API、Veloera 和 VoAPI 签到前先查询今日状态，状态缺失或无效时停止提交。明确不支持或未启用签到的结果会保存在账号上，自动执行会跳过，手动操作可重新检测；用户的签到开关保持原设置。500 等临时服务故障不会被记成“不支持签到”。

发送签到请求或自动点击按钮前，扩展先保存“待确认”记录。提交超时、扩展中途重启或点击后结果不明时，后续操作只查询状态，不再次提交；AnyRouter 没有独立的只读状态接口，这种情况下需要到站点人工核对。人机验证、登录失效、权限不足、无效响应和存储故障不进入自动重试。限流等待按站点共享，对手动操作和跨午夜后的运行同样生效。

## 开发

```bash
npm install
npm run dev       # 拉起 Chrome 加载扩展（热更新）
npm test          # vitest 单测
npm run compile   # tsc 类型检查
npm run build     # 产出 .output/chrome-mv3

```

手动加载：`chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 → 选 `.output/chrome-mv3`。

## 权限说明

- `storage`：本地保存账号数据（不上传任何服务器）
- `alarms`：自动签到定时
- `notifications`：签到结果通知
- `<all_urls>`：向你添加的中转站发起余额 / 签到请求

## 数据安全

所有数据（含 Access Token）仅存于浏览器本地 `chrome.storage.local`。导出的备份 JSON 含明文 Token，请妥善保管。

**登录密码**额外走主密码加密：在「安全」页设置主密码后，密码以 PBKDF2（310k 迭代）派生的 AES-GCM 密钥加密存储，主密码与派生密钥都不落盘（密钥仅存 `chrome.storage.session`，浏览器关闭即清空）。主密码没有找回途径——忘记只能在「安全」页重置保险库，届时所有已存密码会被清除（Token 与 OAuth 记录不受影响）。备份里的密码为密文，换设备恢复需配同一主密码解锁。

自身备份除账号 / 分组 / 标签 / 签到设置外，还含签到记录、模型测试配置与界面偏好：**覆盖导入**整体替换本地；**合并导入**时签到记录按时间新者胜，而模型测试配置与界面缩放视为设备偏好、不覆盖本地（异库合并的密文密钥会被剥离并在导入报告中计数）。
